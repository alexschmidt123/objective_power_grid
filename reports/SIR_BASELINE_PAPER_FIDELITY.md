# Source-verified baseline fidelity

This deterministic SIR ODE study is an adaptation, not an exact reproduction of a published stochastic SIR/SDE experiment. Physics, observation noise, chronological action mapping and horizon5 are common adaptations. Native algorithm operations are distinguished from experimental hyperparameters. `SIR_BASELINE_SOURCE_RECORDS.json` contains pinned upstream revisions, per-file hashes and local verification; config and source manifests seal the adapted execution.

Vendored source is not edited. DAD raw/token adapter equivalence, RL replay/update equivalence, vsOED physical time/log-coordinate tests, Score scalar-head and JAX/Torch/GRU fixtures supplement source hashes. Final scoring uses the same explicit likelihood estimator regardless of training objective; it does not replace native objectives. All deployment policies are amortized or fixed/random; no online action optimizer is invoked by these implementations. Initialization, optimizer, schedule, replay, pretraining, likelihood, source coordinate transforms and final-budget selection are sealed in config/effective-settings/checkpoint metadata. Paper fidelity is not a claim of published SIR result reproduction.
