# MoE-sBOED-v2 candidate: independent routed design readouts

**Development candidate, not a registered successful version.** Architecture is a direct extension of the validated sparse feature MoE, not a collection of independent DAD policies. One shared DAD sum-history encoder produces16-dimensional z. One shared SwiGLU8-wide expert provides a common component through the original shared head. Seven routed8-wide SwiGLU experts retain independent parameters and now each owns a bias-free16→2 design readout D_e.

V1: `latent = H(z + E_shared(z) + sum_selected p_e E_e(z))`.
Candidate: `latent = H(z + E_shared(z)) + sum_selected p_e D_e(E_e(z))`.
Here H is the unchanged shared LayerNorm/linear head; p=softmax(Wz), selected indices are top3. Keep the selected full-softmax probabilities unrenormalized. No arbitrary gain, forced output diversity, role labels or expert activation scaling is added. Owned readouts use the same small normal(.01) initialization as the native shared linear head. All components, including the shared branch, train jointly from scratch.

The existing sigmoid map constrains location designs to[-4,4]^2. No expert emits an independent full policy/history encoder; there is one integrated amortized policy. Total8658parameters, activated6994/history; v1 has8434/6898. A single dense shared FFN of width71 yields exactly8658parameters, providing a parameter-matched dense control. The separately trained shared-only control has5634parameters; it is a control, not registered as a MoE.

The original terminal full-horizon sPCE loss and native balance coefficient.001 remain. No new surrogate information utility or auxiliary competence objective. Pathwise automatic derivatives through the complete simulator/history are exact for a fixed local top-k branch away from switching boundaries. Top-k membership is discrete; this derivative does not include boundary-motion terms of an expected discontinuous routing objective and is not claimed to be its exact global gradient. This approximation is shared with native v1. Finite differences test locally stable branches, including complete30-stage terminal utility. No useful history gradient is detached by the candidate forward computation; detached caches serve diagnostics only.

Deployment: observed history→shared encoder/context→learned sparse router plus shared/routed computations→combined latent design→common feasibility map. No online EIG search, teacher, posterior-conditioned optimization or parameter updates. Frozen uniform intervention distributes the original selected gate mass equally over all seven experts (dense feature mixing, different inference cost); it is explicitly not retraining or uniform random sparse routing. Weakest-slot substitution preserves three distinct active experts and original slot weights, followed by the complete adaptive future trajectory.
