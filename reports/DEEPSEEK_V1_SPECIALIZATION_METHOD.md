# DeepSeekMoE-v1: context-protected expert learning

Foundation: 13681d7091189a4e68056e6a2864dc58f9d5700b, the original validated DeepSeekMoE-sBOED-v1 source. The original policy, trainer, history encoder, simulator and evaluator files remain byte-identical. The candidate uses the SAME DeepSeekPolicy class: 8434 total parameters, 6898 active, one shared width8 SwiGLU expert, seven routed width8 experts, top3, original shared encoder/head. Gate weights retain selected full-softmax mass. No IR,RC,SA orPIMoE architecture/training source is borrowed.

The single methodological change is routed-expert gradient handling. Every10 optimizer updates, use one observed-prefix stage from the fixed cycle1,10,20,29. Split the minibatch at the median of the shared history feature coordinate with greatest observed variance. This uses learned histories, no hidden parameters, scientific role labels, teacher, future utilities to define groups, or extra network.

For cohorts c, L_c=mean_i[1{i in c}*(-terminal full-horizon sPCE_i)]+(n_c/B)*balance. Thus L_0+L_1 equals the original complete loss and g_e0+g_e1 reconstructs its expert gradient. Context gradients are collected before the original full backward pass; only routed expert .grad tensors are subsequently changed. Encoder, shared expert, router and head retain their exact original gradients.

For expert e, prefer the cohort with greater mean selected router gate exposure. This affinity is detached and does not create another routing model. If its gradient u conflicts with the other cohort v, remove the opposing component v'=v-min(0,v dot u)/(u dot u)*u. Set H=u+v'. Admit only finite H with positive alignment to the ORIGINAL summed expert gradient G. Rescale H to norm(G). Otherwise retain G exactly. Tied affinities, empty contexts and zero gradients cause no change. Sparse inactive-expert None gradients remain None.

This is an optimizer adaptation inspired by [gradient surgery](https://papers.neurips.cc/paper_files/paper/2020/hash/3fe78a8acf5fda99de95303940a2420c-Abstract.html), not a claim that H is an unbiased gradient of a new scalar loss. Positive raw-gradient alignment supports local SGD descent; it does not guarantee a finite Adam step, convergence, expert competence or higher EIG. The router still learns gate usefulness through the SAME original full-horizon DAD information objective and the resulting expert features. No separate expert rewards or immediate EIG objective is introduced.

Original B2000,L2000,H30,Adam5e-5/(.8,.998),0.98 schedule,global norm5 clip and four-hour allowance are preserved. Main models initialize fresh seeds101 and102. Specialization backward time is measured separately as a SUBSET of the four-hour budget; it adds no simulator forward calls and no parameters. Extra reproduction, readiness/pilot and post-freeze diagnostic/evaluation costs are separate. Latest eligible checkpoints are frozen before scoring; no official-data selection or retuning.

The bounded pilot uses100 paired fine-tuning steps per arm from the same frozen v1 weights with NEW identical Adam states and learning rate, not a resumed historical optimizer. Both arms see identical simulated draws. One arm uses v1 updates and the other the single proposed procedure. Pilot weights are discarded. Its gate checks finite gradients, exact gradient reconstruction/norm conservation, unchanged other parameter gradients, and nontrivial operation across observed stages. It does NOT certify an EIG improvement.

Specialization must be validated through frozen information interventions, learned-vs-uniform routing, v1/dense/shared-only comparisons, and context-dependent full-horizon utility. Common-prefix interventions compare all35 triples offline, with identical truth/noise/contrast banks. History groups use classifiers recorded during training. Group averages are valid joint-distribution comparisons, NOT claims that one simulated generating theta represents the posterior at one fixed history. No online design search, posterior simulations, teacher or parameter update is deployed.

Counterfactual contextual-set selection uses even development cases and confirmation uses odd cases. No deployed policy or trained checkpoint is selected that way. All-pair context reversals use a conservative3570-comparison normal-MC family correction. Uncertainty is conditional on fixed banks/trained weights; finite development cohorts and only two training seeds limit conclusions.

Primary sources: [DAD](https://proceedings.mlr.press/v139/foster21a.html), [DeepSeekMoE](https://aclanthology.org/2024.acl-long.70/). This learning procedure is a hypothesis to test, not a result established by those papers.
