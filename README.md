# Objective Power Grid

Sequential Bayesian experimental design for power grids, location finding, and SIR models.

```bash
bash run.sh --config configs/power_grid/ieee9_research_eig.yaml --method dad
bash sweep_run.sh --configs configs/power_grid/ieee9_research_eig.yaml --method dad --T 3,5
```

Results go in `experiments/`. [Project rules](AGENTS.md).
