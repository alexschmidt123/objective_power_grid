# CER-MoE-sBOED V3

This is an isolated new proposal, not a relabeling of HEC or earlier V3. Historical
actors, checkpoints and scratch source remain read-only. LabPC is authoritative.
No Step-DAD, cost penalty, specialization reward or diversity reward is used.

The first two validated native vsOED history layers are shared. A common frozen
amortized Bayesian model supplies posterior mean, variance and mixture weights.
Four independent complete action heads receive that context. Each maps to the
entire feasible two-dimensional experiment at every stage through the native
sigmoid bounds. There is no generalist slot, shared action head, residual action
anchor or physical-coordinate mixture.

An action-conditioned native critic estimates Q(h,a), the remaining undiscounted
variational information return. Full routing uses
pi_k=.9 softmax(Q(h,a_k)/tau)_k+.1/4. The four proposals are enumerated to construct
the probabilities, then one categorical expert is sampled and its whole design
is executed. The learned bounded positive temperature is a policy parameter.
The trained uniform arm uses pi_k=1/4 and the identical prepared initialization.
The value network is trained on native information Bellman targets, not a
separate router-quality reward. Policy-dependent target values enumerate all
four complete proposals under the target policy and target critic.

Holding the critic fixed during an actor update, the exact categorical surrogate
J(h)=sum_k pi_k Q(h,a_k) has derivative
sum_k (d pi_k)Q_k + sum_k pi_k grad_a Q_k d a_k.
Both terms are differentiated, including Q-dependent routing and epsilon. Exact
enumeration is the Rao-Blackwellized categorical policy gradient; it avoids a
straight-through estimator and gives every expert a nonzero responsibility
floor. The replay-distribution native actor-critic remains an approximate
off-policy method; this is not an unbiased gradient of exact on-policy MI.
Native Gaussian design perturbations are behavior exploration, as in the parent
off-policy method; categorical exploration is part of pi in actor and target
expectations. No extra entropy, load-balancing or competence objective is added.

Specialization is conditional preparation on data-supported history distributions.
Before preparation, two independent importance-sampling/posterior and suffix
replications estimate action-conditioned *full remaining horizon* values for
nine complete probe designs at three noninitial stages. SNIS uses the exact
Gaussian location likelihood with a full-support .1 prior+.9 frozen GMM proposal.
Every candidate starts from the same prefix and newly sampled conditional theta;
all subsequent observations are resimulated with common future-noise draws.
The suffix follows frozen HEC-v2. The terminal signal is normalized native
log q30(theta|new history)-log qt(theta|prefix). This approximates conditional
variational information gain; finite SNIS and posterior approximation errors
remain. It is not greedy one-step information, a Fisher heuristic, or exact MI.

Four-way clustering alone is insufficient. Calibration histories fit centers;
held-out histories must have occupancy >=.1, silhouette >=.2, four distinct
preferred probe designs, assignment agreement >=.7 between independent complete
MC estimates, and at least two populated groups within each sampled stage.
At least90percent of held-out posterior draws must have ESS >=32/4096. The group
count is not silently forced if these checks fail. The finite probe palette and
fixed continuation are limitations even when these checks pass. No evaluation
bank is used to make the grouping decision.

On support, prepare each specialist with the original native Q design gradient
on its own group, then jointly optimize all experts, shared encoder and routing
from pure native full-horizon variational EIG. No preparation classifier reward
is added. Preparation simulator work, replay work and additional model calls are
reported separately. Both arms get exactly the same prepared state, native
10000-episode batch,1000 new episodes/update,5 critic updates and5 posterior
updates per stage, gamma1, and2000 final updates. Run full then uniform, one seed,
no search, extension or automatic restart.

Compare independently resimulated complete T30 trajectories for full, trained
uniform, each frozen full-arm expert, frozen HEC-v2, native vsOED and compatible
frozen DAD/RL-sBOED/ScoreBED. Generate one new2000-case/1M-prior-contrast bank only
after models are frozen. Include the positive likelihood once. Report conditional
MCSE and paired intervals with primary Holm6 adjustment; one lineage does not
measure training-seed uncertainty or compute-matched external superiority.

Unlike HEC-v2.1, routing cannot be bypassed by a shared feature-fusion action
head. Unlike prior competitive V3, routing is generated by actual proposal
remaining-horizon values and specialization is tested by full-suffix design-value
signatures. Unlike CIAS, there is no independently rewarded counterfactual
teacher. These distinctions are algorithmic descriptions, not a novelty claim.

Current files implement the complete-proposal policy and the support audit.
Training remains dependent on evidence supporting four meaningful groups and
passing native integration checks. Unsupported groups are a substantive negative
result, not an excuse based on unproven novelty.

The first fixed-probe audit was invalidated because the standalone terminal
scorer omitted the normalized density's tiny prior component. Its bytes are
preserved, and its group results are excluded. Native density parity now covers
ordinary draws and extreme tails. The corrected fixed-probe audit still failed
four-group support. Because every center preferred the adaptive HEC proposal to
the coarse fixed anchors, one additional *diagnostic*, declared in
LOCAL_PROBE_CONFIG.json before inspecting its fresh histories, uses comparable
local complete proposals: four axis directions at distances0.25 and0.75 from
HEC, plus HEC itself. Thresholds are unchanged. This is an exploratory refinement
of group discovery, not an architecture/training sweep, extra training seed,
training extension or evidence that the original audit succeeded. There are no
further follow-up audits or forced group assignments.
