# Specialist design

The successful v1 live modules, compatible optimizer state, frozen SG provisional policy, existing approximate-belief model and critic providers are reused. Four specialists retain their mathematical responsibilities. No independent posterior network is trained.

E1 geometry: preserve a fixed copy of the v1 region-feature function, evaluated at the current history/belief and commanded region attention. The live region expert learns an adaptive difference from that anchor. E3 similarly preserves its Fisher/direction-feature function while its live sensitivity expert adapts. Anchors guarantee feature availability on identical inputs, not eventual use or universal accuracy.

E2 discrimination: construct opposed soft hypothesis groups on the existing 64-node GMM quadrature, using command-selected standardized parameter projections. At the three commanded spatial queries compute cross-group Gaussian KL, signed separation and within-group predictive variances. These are exact known-likelihood calculations averaged on an approximate belief quadrature, not EIG. Twelve semantic coordinates remain directly available; a new 36→96→52 learned adapter predicts discrimination at separately rotated feasible probes during preparation. Its target is not the old marginal-moment task or a shared critic score.

E4 sequential opportunities: deterministically approximate the same belief by eight systematically selected support points. For three provisional designs use three moment-matched predictive observation nodes; apply normalized exact-likelihood reweighting and evaluate follow-up designs around the updated belief's source centroid. Twelve protected coordinates encode expected future pair-discrimination and immediate discrete-belief information. A 20→96→52 adapter learns separately simulated second-observation variational-information and remaining-value contrasts. It does not simply reproduce Q(h,a).

The eight-node belief and three-node predictive integration are approximations; moment matching does not make a multimodal predictive distribution Gaussian or exact. They are policy features, never replacements for the final native full-horizon objective or reference evaluator. All hypothetical probes respect the same action bounds.

Phase A uses disjoint saved-parent replay trajectories: 4096 training/512 validation prefixes. No recorded hidden parameters are read. E4 samples latent values from the existing conditional approximate GMM and resimulates two observations with a consistent frozen HEC-v1 continuation, four replicas and common random numbers. Native posterior information increments and the frozen parent native critic supply separate second-step/tail targets. These are preparation surrogates, not exact conditional mutual information.

Only the two new learned adapters/readouts receive 300 Adam preparation updates (batch256,lr0.001). E1/E3 reuse demonstrated representations without forced new common labels. Final learned-competency probes exclude the 12 analytic bypass coordinates. The semantic features are provided by known mathematics; they are not falsely counted as learned competencies. All live experts then receive native EIG gradients. Auxiliary tasks stop before native training.

Provider provenance: the deployed belief/critic feature providers remain the frozen SG providers already embedded in v1. Preparation information-increment labels and tail bootstraps use the newer trained HEC-v1 native posterior/critic snapshot. These distinct approximations are never called an exact common posterior or exact conditional EIG.
