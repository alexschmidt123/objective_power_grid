# Baseline implementation audit

This is a focused implementation/readiness audit, not proof that all historical policies converged. Shared initial settings mean the same benchmark prior, physical initial conditions, observation/noise model, horizon and design constraints. Neural initialization, training objective, optimizer and duration are method-specific. Resource-saving settings are allowed and must be disclosed.

35 focused tests passed, including exact location/upstream vsOED physics, history conversion, likelihood scoring, pinned source hashes, native checkpoint loading, ScoreBED JAX/Torch inference, SIR reference integration and gradients, and bounded actions. Two obsolete tests initially invoked a retired MoE factory; they now exercise the active DAD path for their estimator/accounting assertions. No production algorithm was changed to satisfy those tests.
