# E1 baseline fidelity decisions

Status: DAD, RL-sBOED, vsOED-G-I and ScoreBED are RESOURCE-ADAPTED implementations of the original algorithms on the common bounded location benchmark. This certifies tested algorithm components, not paper-scale convergence or corrected full-budget performance. Five-seed corrected training is still pending for DAD/RL/ScoreBED. Exact upstream commits and file SHA256 maps are in upstream_reference_versions.json; the component CSV is authoritative alongside the qualifications here.

## DAD
Official ae-foster/dad at 4b1008174e1531d1f14601d83cef481c0f586f36: location_finding.py EncoderNetwork/EmitterNetwork, neural/modules.py SetEquivariantDesignNetwork.forward, contrastive/mi.py PriorContrastiveEstimation.differentiable_loss. Local: src/research/dad_location_policy.py LocationDAD and training.py train_spce.

The shared native emitter has F(H)=W sum g(pair)+b and F(empty)=b. Therefore F({x,y})-F({x})-F({y})+F(empty)=0. An independent first design a gives a-b instead; its first-action gradient bypasses the emitter. It is not the same policy class. Restore first_design_revision=1, 256/16 ReLU sum encoder and linear emitter, and disable historical global gradient clipping. Retain historical revision-2 loading. Official empty_value is allocated but unused by forward; not reproducing that dead parameter does not change the functional policy. Common sigmoid box mapping is explicitly a benchmark adaptation. Official-source fixed draws match actions, physical likelihoods, sPCE positive/negative terms, full-rollout gradients and one Adam step within rtol1e-8/atol1e-9. Empty-history gradient/invariant regressions also pass.

E1 uses ONE native policy per independently trained score bundle, not best-of-five restarts. Predeclare10014 initialization/normalization +692990 score +296996 policy =1M. No split tuning against EIG. Reduced batches and pretraining are severe resource restrictions, not a newly designed objective. The older80:20 intervention and crossings remain development evidence. Official versus vendored CPU comparisons match289 arrays bitwise, including score/policy updated parameters, EMA, sampler draws, physical likelihood and design gradients. EMA inference bridge is tested separately. Native upstream publication linkage is recorded conservatively: no claim of an author-certified artifact tag.

## Limits and execution gate
No corrected EIG is invented. Historical DAD/RL/ScoreBED results cannot be relabelled as corrected. All updates are isolated; historical campaigns remain immutable. Reference one-update tests establish numerical behavior on their fixtures, not every possible training trajectory. SIR adaptations require their own fidelity gate; location PASS does not certify SIR. Consumed seed8831001 is excluded from selection. Freeze a genuinely fresh confirmation bank only after development and analysis settings are fixed.
