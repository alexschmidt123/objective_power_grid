# Original-baseline methodology audit

This report compares official papers, pinned executable source, and the saved adapters. The40-row CSV is component-level and explicitly distinguishes historical deviations from corrected behavior. It is not a blanket certificate of a paper-scale reproduction. Original source commits and file hashes are frozen in upstream_reference_versions.json. Garage is pinned to release2021.03.0, required by RL-BOED, with metadata-only compatibility shims; native network/distribution/update class bodies execute unchanged.

Confirmed departures: historical DAD uses an extra independent first-design parameter and globalnorm5clipping. The official executable SetEquivariantDesignNetwork.forward applies its shared emitter to zero encoding at empty history; its empty_value parameter is present but unused in that forward path. Corrected DAD selects revision1 and no clipping; it retains original256/16sum encoder, linear emitter, Adam and sPCE. Original historical checkpoints cannot simply be called exact DAD.

Historical RL-sBOED was explicitly simplified: added stage coordinate, different history normalization and initialization, gamma1, altered temperature objective, temperature clamp, norm1clipping and reduced updates. Corrected mode executes official two-critic nativeSAC/REDQ class bodies, restores original affine history normalization, tanhGaussian distribution, discounted.9target, native entropy/target updates, and64updates/collection. No ten-critic source ensemble is assumed. Replay1M and contrastL1024 remain disclosed computational restrictions. Reference sourceCLI defaults sometimes differ from the paper-selected source hyperparameters; the latter and experiment scripts govern tau.001 and actorLR1e-4.

The bounded vsOED branch passes an independent official-source full-update test: actor, critic and every GMM posterior parameter match bitwise. Its upstream simulator takes the natural logarithm of signal; shared likelihood follows executable source, not an inconsistent printed signal expression. There is no bounded-branch input compression, policy trust region, or added actor gradient clip.980versus10001actorupdates is a substantial optimization-budget limit. No new vsOED algorithm is introduced to improve its number.

ScoreBED keeps official JAX marginal score matching, conservative transformer and native policy gradient. Public source preset uses an equal temporalGaussian/randomProjection mixture, whereas the main paperEq87specifies the temporalGaussian sampler. Corrected mode selects that paper sampler, mapped to the common design bounds, and restores five final-policy restarts. Every restart uses the same seed-specific frozen score bundle and retains native policy initialization/objective/optimizer. Each final restart is scored on independent validation771001; choose the maximum as native restart reporting does. This is distinct from checkpoint selection: every candidate is its final-budget checkpoint; no development1001or consumedfinal8831001case is used for selection. Restart selection precision is reduced to128/L16384and is a disclosed resource adaptation, not a paper-scale replication.

Numerical tests compare actions, physical likelihoods, losses/rewards, gradients and updated parameters. DAD's original loss body is executed with a deterministic trace harness; this replaces stochastic trace construction, not the likelihood-ratio formula. NativeRL source likelihood uses actual Pyro condition/trace; Garage launcher infrastructure is not required. ScoreBED uses independent Python processes for original and vendored JAX modules. Smoke tests add serialization/feasibility coverage but are not the basis of methodological equivalence claims.

Corrections are opt-in in an isolated git worktree. Active LabPC MoE and ScoreBEDallocation jobs, UbuntuSIR jobs, historical failures and consumed final results are unmodified. The one-million-episode budget is a constrained study, not evidence of convergence or equivalence to published EIG. Resource costs and final results remain pending until actual full runs finish.
