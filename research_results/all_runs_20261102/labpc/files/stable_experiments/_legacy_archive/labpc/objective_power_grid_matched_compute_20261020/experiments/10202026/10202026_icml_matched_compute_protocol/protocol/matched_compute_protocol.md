# Matched-computation ICML protocol
E1 compares final EIG under a common allocated computation ceiling, not full convergence. Baseline objectives, native architectures, optimizers, minibatches, replay/target rules and LR/exploration schedule formulas remain unchanged. Four MoE architectures retain corrected ST routing and switching. Extra primary episodes are neither the comparison unit nor a stopping requirement.

Location recommendation: four hours of exclusive RTX4090-backed training wall time per complete learned method/seed. This is a proposal pending common-hardware phase calibration. DAD reference training measured11918s; native RL is genuinely multi-hour. ScoreBED's 5080 measurement is reported separately:10000score updates/868.7s, failed at checkpoint serialization; it cannot calibrate equal4090-hours. Published full score pretraining need not fit the cap. Native score/policy phase counts are scaled using timing only while preserving selected phase ratios, batches and original scheduler horizons. No favorable EIG is used for the allocation. Failure to obtain a trained policy is explicit.

SIR has no assigned primary compute budget yet; do not invent one or launch its matched-compute study before benchmark-specific native timing is available. No conversion factor between4090 and5080 is assumed. The primary time-matched cohort should use4090;5080 cohorts are separate hardware strata with model-work and measured runtime reported. A4h location budget means at most180GPU-backed hours for45trained runs before shared-base physical reuse, validation and evaluation. State this resource cost explicitly.

Clock includes launcher setup, compilation, normalization, fresh simulations and contrasts, likelihood/gradient work, posterior/score learning, RL replay, checkpoint I/O and all pretraining. Validation and final scoring are logged separately. Fine-grained utilization is not confused with GPU occupancy or FLOPs. Method-specific primary/model/likelihood/optimizer counts accompany runtime. A residual model is charged its seed-specific frozen base once per complete method even if physical computation was shared; no cross-hardware time credit. The same base is used within each residual pair.

Stop at native complete-unit boundaries using the conservative observed unit-time bound. Retain the latest checkpoint whose charged training time is within quota, regardless of EIG. Report unused quota and all overshoot; no work disappears from the ledger. A separate generous episode cap is only a safety guard; reaching it early is reported rather than called compute-quota exhaustion. Freeze checkpoint cadence900training-seconds, selection, phase plans and permissible boundary tolerance before replication. No plateau or maximum-EIG requirement.

E1 contains Random once and nine trained methods at seeds101–105. Use paired benchmark-specific development banks and independent confirmation after freezing. Report mean/seed SD, trajectory MC uncertainty, paired comparisons, realized costs and budget compliance. Random is untrained, not five learned replicates.

E2 primarily reuses saved E1 cost-indexed checkpoints and scores. Plot EIG against charged time, simulator/likelihood work and secondary episodes only over measured overlapping ranges. Include upfront training; no invented zero-EIG policy before ScoreBED has a trained policy. Do not automatically launch another campaign.

E3 stays limited to single-expert/capacity-matched controls, fixed versus learned routing, relaxed versus ST and forced versus learned switching, plus a small declared sensitivity set. No E2/E3 training is released now.

Existing reference pilots remain unmodified. Historical1M runs remain pilots. Full five-seed release is false until budget/source/config/bank/analysis freeze. No grid work.
